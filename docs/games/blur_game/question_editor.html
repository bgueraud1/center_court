Questions

Add as many cards as needed, then submit them in one batch.
Open questions need the question text, the open answer, an optional “player answer” flag, a difficulty, and tags.
QCM questions need four options plus the correct letter.
True / False questions need the statement, the correct truth value, an optional explanation, a difficulty, and tags.
Publication is not automatic. Every question goes through manual review before going live.
